## Facebook — Omarchy users group

> Omarchy made our agents system citizens — but they all wake up every
> morning with amnesia. Claude Code doesn't know what Codex did yesterday.
> Nobody remembers that this app crashed before, or what fixed it.
>
> So I built Omnemo: one shared memory for every agent harness on the box.
> Save a fact in one agent, recall it from any other. Human-style recall too —
> memories blend similarity, recency, and importance, and different kinds of
> memories fade at different rates, like yours do.
>
> The part I'm proudest of: it's a glove, not a fork. Built entirely on
> Omarchy's own extension points (skills, user plugins, hooks), so it survives
> every `omarchy update` — tested through a real update including a harness
> binary upgrade. It's also crash-safe: we SIGKILL'd the agent mid-save in
> testing and the memory survived (there's a demo script in the repo).
>
> And it fits the family: Omakase → Omakub → Omarchy → Omnemo. 😄
>
> Install: `pip install omnemo` — or just open your agent and say
> "Install Omnemo — follow INSTALL.md" and it does the rest.
>
> MIT licensed, free, on GitHub: https://github.com/GuyMannDude/omnemo
> I'm 73 and building this stuff for the joy of it — feedback very welcome.
